# Third-party data acknowledgements

**CSS standard named colors (reference data only).**

The 148 CSS color keyword RGB values used in `crates/color-core/src/css/mod.rs` are
standardized by [W3C CSS Color Module Level 4](https://www.w3.org/TR/css-color-4/#named-colors).
They were cross-checked against the MIT-licensed reference table
[https://github.com/colorjs/color-name](https://github.com/colorjs/color-name).
The package is not installed, linked, imported or included as a runtime dependency.
The implementation of the parser and color engine is first-party Rust code.
